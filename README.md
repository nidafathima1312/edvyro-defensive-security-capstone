# Defensive Security Assessment Capstone - Student Portal

**Track:** Cyber Security  
**Task:** Defensive Security Assessment Capstone  
**Author:** Nida Fathima  

## Overview
This repository contains the final capstone defensive security assessment of a local student portal application. It documents the assessment scope, authorized rules of engagement, reproducible vulnerability findings, applied security remediations, and before-and-after retest evidence.

## Repository Structure
- `README.md` - Executive project summary.
- `assessment-report.md` - Scope, authorization statement, rules of engagement, and findings matrix.
- `remediation-and-retest.md` - Technical code remediations and before-and-after retest results.

## Key Assessment Results
- **Scope & RoE:** Established strict authorization and rules of engagement limited to localhost (`127.0.0.1`).
